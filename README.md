# JavaScript Calculator

Live Demo: [Calculator App](https://lovishjaswal.github.io/Calculator-App/?utm_source=chatgpt.com)

A simple calculator built using HTML, CSS, and JavaScript.

This project was created while learning JavaScript fundamentals, DOM manipulation, event handling, and basic arithmetic operations.

---

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear functionality
- Interactive button-based interface

---

## Technologies Used

- HTML
- CSS
- JavaScript

---

## Purpose of This Project

The main goal of this project was to practice JavaScript logic building and understand how user interaction works in frontend applications through DOM manipulation and event handling.
